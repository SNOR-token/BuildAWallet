An execution request means a request that reaches the signing/execution pipeline; blockchain gas, RPC provider charges, bridges, swaps, token fees, compliance vendors and other third-party costs are not included. Pricing is an initial launch schedule and can be revised before public billing is enabled.

Why price this way?

Agent infrastructure is different from a human wallet SDK. The valuable unit is constrained authority: an agent receives a wallet, a policy envelope, and permission to perform bounded financial actions. Pricing therefore combines active agent wallets with policy and execution usage instead of charging only by human monthly-active-user counts.
