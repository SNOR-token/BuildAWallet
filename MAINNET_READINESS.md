# Release gate: mainnet wallet services

**Decision: NO-GO for handling real funds.** This assessment covers the staging branch as inspected on 2026-09-24. Passing local tests does not constitute a security audit, chain integration test, or production deployment.

| Area | Evidence | Gate before handling funds |
| --- | --- | --- |
| HUMAN extension | The downloadable Manifest V3 popup imports a JSON design only. A separate `extension-wallet/` prototype creates and recovers a Sepolia account and signs reviewed Sepolia native transfers offline. It has no RPC, broadcasting, site permissions, mainnet configuration or production release process. | Integrate and independently review key lifecycle and recovery, chain adapters, explicit origin permissions, transaction simulation and approval, RPC/broadcast reconciliation, hardened update path and browser testing before handling real funds. |
| NON-HUMAN API | `agent_protocol.py` stores encrypted signing keys and execution state in local SQLite, but the public container no longer mounts its routes or includes its signing code. `cloudflare-agent/` is a D1-backed, watch-only Sepolia Worker preview; it cannot approve, sign, price, broadcast or manage mainnet wallets. | Define a separate durable execution and key-management boundary, multi-tenant operator authority, RPC trust and rate limits, crash recovery, on-chain reconciliation, approval audit, and tests before routing `/v1/*` publicly. |
| Replay control | This branch commits the `executing` state before external broadcast and marks exceptions `execution_unknown` to prevent blind retries. | Reconcile uncertain outcomes by transaction fingerprint and chain receipt; test process death at each signing/broadcast transition, concurrent operators, nonce/UTXO contention and chain reorgs. |
| Destination policy | An empty allowlist now denies when `deny_unknown_destinations=true`. | Validate destination and asset against the wallet's actual chain; fuzz amounts, precision, NaN/infinity, encodings, and unsupported operations. |
| User authentication | Studio Pages Function requires Cloudflare Access JWT; its team domain and audience are not configured in this environment. Blueprint API remains public. | Configure and verify Access, protect personal API records, bind them to verified identities, and confirm account recovery before exposing user wallets. |
| Cloudflare release | `wrangler whoami` reports unauthenticated; D1 config contains a placeholder database ID; `/v1/*` has no Worker migration. | Provision D1 and Access, deploy the HUMAN Worker, verify real routes and monitoring, and perform controlled production checks with no real funds initially. |
| Public blueprint links | The public save endpoint now uses 26 random characters for new share codes and does not collect email; stats no longer disclose private codes. Existing shorter links remain usable and anyone who has a link can read its design. | Keep secrets and private account records out of shareable blueprints. Build identity-bound private records separately before claiming personal storage. |

The exact broadcast environment switch is intentionally left **off**. No real-fund transfer or production wallet deployment was attempted. The checked-in extension ZIP remains a design preview; do not label it a wallet or solicit deposits to it.

Local checks on this branch: `.venv/bin/python -m pytest -q` (4 passed), `node tests/studio_access.mjs` (passed), `node tests/vault.mjs` (passed), `node tests/agent_worker.mjs` (passed), `npm ci && npm test && npm run build` in `extension-wallet/` (passed), `wrangler deploy --dry-run --config cloudflare-agent/wrangler.jsonc` (bundled), `python extension/package.py` (packaged). The focused transaction test exercises uncertain broadcast in a local-only test app; the public server deliberately has no `/v1` routes. A clean public-image dependency install imports the reduced server file set without the legacy signer. `fastecdsa` was pinned below 4 because version 4 no longer exports the module required by `bitcoinlib`.

GitHub Actions run #16 failed before jobs started because the GitHub account is locked for a billing issue. Local tests do not replace a green CI run. The root `main` branch also triggers a see.io deployment, separate from Cloudflare Pages. Check both hosting targets before merging this staging branch.
